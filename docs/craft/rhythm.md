# 句式与节奏（Rhythm）

> 读者说「读着累」或「像 AI」，大多不是词不够好，是**节奏太均匀**：句句等长、段段同构、章章同密度。
> 本表管呼吸——句子的长短、段落的疏密、一章的起伏、用词的分量。改句子之前先改呼吸。

## 一、节奏的三层

| 层 | 出问题的症状 | 改在哪 |
|---|---|---|
| **句内** | 一句读不完；三个「的」连用；因果词堆叠 | 第二节 |
| **段内** | 一屏一段；连续五段等长；开头都是「他……」 | 第三节 |
| **章内** | 全章一个情绪；场景长度一样；没有起伏 | 第四节 |

三层里，**章内**的问题最贵（读者直接弃章），**段内**的问题最显眼（一眼像 AI），**句内**的问题最好改。

## 二、句内：让句子有长短

### 三条硬规则

1. **一段里至少一个 ≤8 字的短句**。全是长句，读者没有换气的地方。
2. **主谓之间不塞超过 12 字的定语**。「那个曾经在城南开了十年药铺、后来被一把火烧干净的老头」——
   读者读到谓语已经忘了主语是谁。
3. **三个「的」连用就是翻译腔**：「他的新买的黑色的旧车」。删到两个以内，或者换成短句。

### 让动作承接，别让连词承接

「因为下雨，所以他没出门」→「雨没停。他没出门。」
「他感到非常愤怒，于是握紧了拳头」→「他握紧了拳头，指节发白。」
因果词（因为、所以、于是、因此）是解释，动作才是演示。一章里因果词超过三处，就是作者在讲道理。

### 单句成段：只用在这三个地方

- **转折**：「他笑了。」（下一段：笑到一半停住。）
- **动作落点**：关键一击、关键一步、关键一句。
- **判决**：一句下结论的话，说完就停。

单句成段是重音，一段里用两次就不重了；一章里超过十次，读起来像短视频文案。

### 整齐句式要拆

三句排比、对仗、每句等长、每段结构一致——人写不出这么整齐的节奏。留最有力的一句，其余拆成短句
或换成动作。对举句（「不是 A，而是 B」）一章超过两次，就到了该删的时候（见 `voice.md` 第一节）。

## 三、段内：手机屏上的疏密

- **一段一个意思，3–5 行封顶**。手机一屏大约 15–20 行；超过五行的一段，读者会跳。
- **对话独立成段**，动作独立成段，心理描写不超过两句——心理是最容易写成说明书的段落。
- **连续五段同长度 = 视觉疲劳**。长短交错：短、短、长、短、中。
- **段首不要连用同一种句式**。「他……他……他……」连着三段，是 AI 最典型的指纹之一。

`novel_write` 会给可数的症状：平均段长、对话占比、重复的句首、句长波动（等长段/缺碎句）、
比喻密度与连用、极端词密度、套话重复。它们是**症状**，不是判决——
数字难看的地方，回去读那一段，看是不是真的卡。

## 四、章内：起、压、爆、收

一章是一个小故事，四拍缺一拍，读者就会在缺的那一拍流失：

| 拍 | 作用 | 常见错误 |
|---|---|---|
| **起** | 一个具体的现场，人物已经在动 | 先交代背景、天气、身世 |
| **压** | 阻力加码，主角的选择变窄 | 阻力是抽象的（「局势危险」）而不是具体的人 |
| **爆** | 一次兑现：反击、发现、决定 | 兑现是主角自嗨，没有见证者 |
| **收** | 断在一个未完成的动作或新信息上 | 断在情绪抒发、总结、空话 |

### 场景与密度

- 一个场景 300–800 字，一章 3–5 个场景；场景之间用动作或时间跳转，不要用「与此同时」。
- 一章的配额：**一个新信息、一次兑现、一个钩子**。三样都没有，这一章就是在原地打转。
- 免费站把「爆」提前、加密；付费站允许两三章蓄力，但每章仍要有新信息（见 `platforms.md`、`payoffs.md`）。

### 允许一次情绪不闭环

真实的人不会「先愤怒、再释然」。一章里可以有一次情绪跳跃或不解释的反应——那是人味，
但只能一次，多了就是失控（见 `voice.md` 第三节）。

## 五、用词的分量

- **动词优先**。形容词和副词是税：能写「他把杯子放下」，就不写「他轻轻地放下杯子」。
- **成语一章不超过两个，且不连用**。四个字一叠，画面就没了。
- **比喻一处只给一个**，而且要从人物的经验里长出来：铁匠的比喻不该出现在书生嘴里。
- **网络语与热梗一章最多一个**，而且要角色说，不要旁白说——旁白用梗会立刻过期。
- **「味儿」词是效率工具**：打脸、碾压、逆袭、装逼、封神，用对了省一整段解释，用多了廉价。
  判断标准：这个词是在**替代**一段描写，还是在**替代**一次思考？后者就删。
- **旁白可以书面，对话必须口语**。让对话和旁白用同一种语言，是很多稿子「不像人写」的根。

## 六、朗读与量化

1. **读出声**。卡住的地方，就是句子太长、定语太多、或者太书面。
2. **看三个数**：平均段长（经验值 40–80 字）、对话占比（经验值 30–50%）、重复句首（越少越好）。
3. **数一拍**：这一章的「爆」在第几段？如果在最后 10% 才出现，前面就是在拖。
4. **换一段对照**：拿榜单上同赛道的任意一段，比一比句长和段落密度——差异通常比你以为的大。

## 七、自检

- [ ] 这一段有没有一个 ≤8 字的短句？
- [ ] 有没有一句话读完要换气？拆开。
- [ ] 三个「的」连用了几次？
- [ ] 因果词出现了几处？能换成动作吗？
- [ ] 有没有连续五段等长？有没有连续三段同一个开头？
- [ ] 这一章的「爆」在哪一段？前面是不是在拖？
- [ ] 章末断在动作/信息上，还是断在情绪总结上？
- [ ] 成语、比喻、热梗，各自超量了吗？
- [ ] 读出声，卡了几处？
