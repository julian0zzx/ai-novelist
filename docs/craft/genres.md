# 题材与赛道（Genres）

> 题材不是标签，是**读者点进来时买下的那个承诺**：他要在多少章内，看到什么样的兑现。
> 本表给赛道判断与雷区，不预测任何题材的冷热；榜单是结果，不是原因。

## 一、先说清三件事

选题阶段答不出这三个问题，第一章就不要写：

| 问题 | 答不出来会怎样 |
|---|---|
| 读者为**哪一种体验**来 | 写成设定展示：每章都有新信息，没有一章兑现 |
| **章级兑现**是什么 | 卷末有大高潮，中间二十章读者不知道在等什么 |
| 这个赛道的**雷区**在哪 | 踩了不自知，书评区骂点集中在你没意识到的地方 |

「题材」不是「世界观」。修真、末日、星际是**设定**；升级、复仇、被偏爱、搞事业是**体验**。
读者买的是体验，设定只是承载体验的容器。同一套设定可以写成完全不同的两个赛道。

## 二、赛道谱系：核心欲望 × 兑现方式

### 男频常见赛道

| 赛道 | 核心欲望 | 每 2–3 章要兑现什么 | 常见死法 |
|---|---|---|---|
| **升级流**（玄幻/仙侠） | 变强、被看见 | 一次可见的突破：境界、名次、战力差 | 只有修炼没有对手；瓶颈写成流水账 |
| **无敌流 / 开局即巅峰** | 碾压的快感 | 一个新的「不知天高地厚」的人撞上来 | 没有配得上的对手，三章后无戏可唱 |
| **系统流** | 有外挂、有指引 | 一个新任务 + 一次超预期完成 | 系统替主角做决定，主角沦为执行器 |
| **都市逆袭**（赘婿/神医/兵王） | 被轻视后的反转 | 一次身份/能力的局部揭穿 | 打脸对象一次比一次弱；女性角色只做奖励 |
| **历史/权谋** | 在规则里赢 | 一次布局得手或一次代价 | 现代思维硬套古代规则；考据错漏 |
| **无限流/诸天** | 陌生规则下的生存 | 一个新副本的核心规则 + 一次破局 | 副本只是换皮；主线被副本淹没 |
| **悬疑探案** | 解谜的智力快感 | 一条新线索 + 一次误判 | 线索不给读者；凶手靠巧合落网 |
| **末世/科幻** | 秩序崩塌后的重建 | 一次资源/规则的重新分配 | 设定说明压过生存压力 |
| **游戏/竞技** | 弱者翻盘的确定性 | 一场有来有回的对局 | 数值自嗨；对手降智 |
| **军事/谍战** | 信念与智斗 | 一次身份暴露的危机 | 专业性不足，靠巧合推进 |

### 女频常见赛道

| 赛道 | 核心欲望 | 每 2–3 章要兑现什么 | 常见死法 |
|---|---|---|---|
| **宅斗/宫斗** | 在压制中反制 | 一次反击得手 + 一次新压制 | 反派蠢；主角只会忍到最后一章 |
| **现代言情**（甜宠/先婚后爱） | 被偏爱、被选择 | 一次具体的偏爱行动 | 只靠旁白说「他爱她」；男主万能 |
| **虐恋/追妻** | 情绪债的清算 | 一次亏欠被看见 | 虐完不补偿；误会靠不说破硬拖 |
| **职场/搞事业** | 主体性与掌控 | 一次专业上的胜利 | 事业线给恋爱让路；专业细节空 |
| **年代文** | 在匮乏里把日子过好 | 一次生活层面的改善 | 时代细节靠标签；金手指过大 |
| **穿书/快穿** | 改写既定命运 | 一个新世界/新身份的核心矛盾 | 世界只是换皮；原剧情当拐杖 |
| **种田/基建** | 从无到有的建设 | 一个具体成果落地 | 只有清单没有冲突；数字流水账 |
| **校园/青春** | 纯粹关系与成长 | 一次关系推进或一次伤害 | 成年人思维；冲突靠误会 |
| **女频悬疑/无限流** | 在危险中保持清醒 | 一条线索 + 一次身份反转 | 恐怖靠形容词；规则不闭合 |
| **纯爱/双男主** | 关系张力与被承认 | 一次靠近或一次退让 | 无视平台分级与合规要求 |
| **现实向/治愈** | 在普通生活里被理解 | 一次被看见的小胜利 | 说教、煽情、狗血；困境解决得太容易 |

> 表里的「每 2–3 章」是经验值，不是规则：免费站要更密，付费站可以更疏（见 `platforms.md`）。

## 三、复合题材：主赛道 + 调味

一章只能让读者等一件事。所以复合题材要分主次：

- **主赛道**决定 70% 的章级兑现——读者冲它来，就不能断供。
- **调味**决定新鲜感——它提供的是「同一个体验的不同包装」，不是第二个承诺。
- 判断方法：把两个题材的「章级兑现」各写一句，能合成一句的是调味，合成两句的是双主线——双主线在网文里几乎必崩。

**混搭失焦的三个信号**：标签里有互相抵消的承诺（甜宠 + 虐恋 + 无 CP）；前三章各讲一个赛道；作者介绍里说「这本融合了 A、B、C、D」。

标签怎么写见 `naming.md` 第三节，那里管的是「给算法和读者的分类信号」，这里管的是「你到底在写什么」。

三种特殊形态另见表：出海改写看 `overseas.md`，二创边界看 `fanfic.md`，改编成剧看 `script.md`。

## 四、赛道与频道、平台

同一个赛道，在不同频道和平台上要改的是**密度和顺序**，不是内核：

- 男频的兑现偏「外显」：围观者反应、对手难堪、可量化的资源差。
- 女频的兑现偏「关系」：具体的偏爱行动、被看见的瞬间、选择权回到自己手里。
- 免费站把第一个兑现提前到第一章；付费站允许用前三章立承诺（见 `platforms.md`）。

选赛道时先确认频道，再确认平台——顺序反了，会写出「在免费站连载的付费站节奏」。

## 五、选赛道的四条硬标准

1. **燃料够不够**：这个赛道要的素材（专业细节、生活经验、阅读积累），你能不能持续供给 30 万字以上？
2. **能不能一句话说出章级兑现**：说不出来，说明你选的是设定，不是赛道。
3. **你读不读这个赛道**：不读的人写不出这个赛道的「读者正在等什么」。
4. **雷区你能不能接受**：每个赛道都有不能碰的东西（合规、专业门槛、读者洁癖）。不能接受就别硬写。

四条里有一条是「否」，换赛道比改文便宜。

## 六、雷区

- **把跟风当选题**：榜单上的书是结果，它成功的原因往往在榜单之外（作者积累、平台推荐、时间点）。
- **把设定当题材**：写了三十页世界观，读者还是不知道每章能得到什么。
- **题材混搭失焦**：两个承诺互相抵消，读者两个都不信。
- **选了自己不读的赛道**：写得出套路，写不出这个套路的「为什么好看」。
- **金手指盖过赛道**：外挂强到不需要冲突，赛道就不成立了（见 `novel_plan operation="cheat"` 的代价与限制）。

## 七、自检

- [ ] 能不能用一句话说出「读者每三章得到什么」？
- [ ] 主赛道是哪一个？调味是哪一个？两者会不会互相抵消？
- [ ] 前三章是否已经给出主赛道的第一次兑现？
- [ ] 这个赛道的常见死法，我犯了哪一条？
- [ ] 我能不能持续供给这个赛道的燃料到完本？
- [ ] 频道与平台选对了吗？密度是按哪个站调的？
- [ ] 有没有踩到题材本身的合规红线？
