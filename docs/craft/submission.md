# 投稿与过审（Submission）

> 投稿不是「把稿子发出去」，是**用平台能判断的格式，证明这本书值得签约**。
> 先准备材料，再谈文笔；材料不齐，编辑看不到文笔。

## 一、投稿前 10 项

- [ ] **字数**：达到目标平台当期的最低签约/推荐门槛（以官方公告为准，不要信旧帖）。
- [ ] **更新**：有稳定的更新计划；断更风险要提前说明。
- [ ] **前三章**：开篇 300 字进事件；第一章末有钩；第二章有新信息；第三章有承诺。
- [ ] **书名**：包含题材词 + 身份/能力 + 冲突/爽点（见 `naming.md`）。
- [ ] **简介**：一句话版 + 一段版 + 三章版，三版都能独立成立。
- [ ] **标签**：3–5 个，和内容一致。
- [ ] **敏感内容**：自查高危类别，按平台后台/当期规范处理，不赌。
- [ ] **错别字**：的地得、在再、做作、账帐、即既——逐章过。
- [ ] **断章**：每章末有具体钩子，不是空话。
- [ ] **材料**：投稿邮件/后台表单要求的文件、字数统计、联系方式。

## 二、三章体检（编辑只看这三章）

| 章 | 必须做到 | 常见问题 |
|---|---|---|
| **第 1 章** | 300 字内进事件；主角做一个有代价的选择；章末钩 | 先写身世/世界/天气 |
| **第 2 章** | 升级冲突；给新信息；让读者看到主角的能力/性格 | 重复第一章的冲突 |
| **第 3 章** | 给一个阶段性兑现；抛出卷级问题 | 还在铺垫，没有兑现 |

### 三章自检

- [ ] 第一章第一段有没有一个动作？
- [ ] 三章里主角有没有主动做过一个决定？
- [ ] 三章里有没有至少一次「值了」的兑现？
- [ ] 反派/阻力有没有具体到人？
- [ ] 三章结束，读者能不能说出「这本书要干嘛」？

## 三、简介三版模板

### 一句话版

```
[身份]在[困境]里，决定[具体行动]——但[代价/阻力]。
```

### 一段版

```
第一句：异常/冲突（具体场景）。
第二句：主角要什么、谁挡着。
第三句：他付出的代价或发现的秘密。
最后一句：一个具体的问题/威胁，不要总结。
```

### 三章版（300–500 字）

按「事件 → 升级 → 承诺」写，不要写成全书梗概；结尾停在第三章的钩子上。

## 四、敏感内容自查（类别，不是词库）

平台词库会变，**不要依赖任何第三方「违禁词大全」**。按类别自查，再以平台后台为准：

- 色情/低俗：性行为细节、未成年人性暗示、露骨身体描写。
- 暴力/血腥：过度细致的伤害描写、虐待动物/未成年人。
- 政治/历史：真实政治人物、事件、领土/民族问题的影射。
- 宗教/迷信：现实宗教的贬损、邪教/封建迷信的鼓吹。
- 违法/犯罪：制毒、诈骗、赌博等可操作细节。
- 现实人物/名誉：影射真实人物、诽谤、隐私。
- 侵权：他人作品的角色、设定、大段文字；同人商用尤其注意（边界见 `fanfic.md`）。
- 平台特有：引战、诱导关注、联系方式、拼音/乱码规避。

> 处理原则：**能删就删，不能删就改，改不了就换平台**。不要用谐音/符号规避审核——那是封号风险，不是创作技巧。

## 五、错别字高频对

`novel_repo operation="submission"` 会先跑一遍**确定性校对**：只查「怎么写都是错」的固定词形（帐号→账号、
时侯→时候、既使→即使…）与标点形态（`...`、`。。`、中文之间夹半角逗号），报出条数与所在章，可整批替换。
它**不查** 的/地/得、在/再 这类要句法判断的用法，也不会说「校对通过」——没查到不等于通读没漏。
敏感词同样不在自动检查里，按下表人工过。

| 正确 | 常见错 | 记法 |
|---|---|---|
| 的 / 地 / 得 | 混用 | 定语「的」、状语「地」、补语「得」 |
| 在 / 再 | 混用 | 「在」是位置/进行，「再」是又一次 |
| 做 / 作 | 混用 | 具体动作用「做」，抽象/书面用「作」 |
| 账 / 帐 | 混用 | 钱相关用「账」 |
| 即 / 既 | 混用 | 「即」是就是/立刻，「既」是已经/既然 |
| 登录 / 登陆 | 混用 | 网站用「登录」 |
| 部分 / 部份 | 混用 | 规范用「部分」 |
| 冲 / 充 | 混用 | 「冲」向前，「充」装满 |

## 六、投稿记录表

每次投稿都记，不要靠记忆：

| 日期 | 平台 | 字数 | 结果 | 拒因/反馈 | 下一步 |
|---|---|---|---|---|---|
| | | | | | |

拒因要**照抄原话**，不要自己总结成「文笔不好」；平台拒因通常指向**题材匹配/字数/更新/开篇**，
不是文笔。

## 七、被拒后的诊断顺序

1. **题材/平台是否匹配**：把女频文投男频站，改文笔没用。
2. **字数/更新是否达标**：门槛没过，编辑不会看内容。
3. **前三章是否留人**：用 `hooks.md` 和 `voice.md` 过一遍。
4. **书名/简介是否说清卖点**：点击率低先改这里。
5. **最后才是文笔**：文笔是加分项，不是入场券。

## 八、上架/付费点前

- 付费点断在最大信息差上，前一小段给小兑现（见 `hooks.md`）。
- 上架前 3 章不要换地图/换主角；读者刚付钱，先给熟悉感。
- 首订低先看**追读转化**，不要立刻改文；改文会让已读读者困惑。
- 记录首订/均订/追读，用 `novel_assess` 抄录，按 30 天同品类中位数比较。

## 九、不要做的事

- 不要一稿多投到同一平台的不同编辑（按平台规则来）。
- 不要买数据/刷追读；平台会清洗，且会连累后续推荐。
- 不要在简介里写「必看」「神作」「不输××」。
- 不要用 AI 生成投稿信；编辑一眼能看出来。
