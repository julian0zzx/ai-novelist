# 爽点与打脸（Payoffs）

> 爽点不是「主角赢了」，是**读者替主角憋的那口气终于吐出来**。
> 没有蓄力就没有释放；没有见证者，胜利只是主角的自嗨。

## 一、爽点的基本结构

```
压抑（读者替主角憋气）
  → 释放（主角用具体行动翻盘）
  → 外显（围观者的反应、对手的难堪、资源的量化）
  → 余波（代价、关系变化、下一层压力）
```

四段缺一不可。最常见的失败是只写「释放」，不写「压抑」和「外显」——
读者没憋过气，看到赢也不会爽；没人看见，赢了也等于没赢。

## 二、打脸四拍

| 拍 | 功能 | 写法 | 常见错误 |
|---|---|---|---|
| **嘲讽** | 让读者站到主角这边 | 反派当众贬低，具体到人格/出身/能力 | 嘲讽太轻，读者不恨 |
| **压制** | 把主角逼到看似无解 | 规则、实力、人脉全面劣势 | 主角其实有底牌，紧张感为零 |
| **反转** | 用**已经埋过**的信息翻盘 | 主角亮出证据/身份/实力 | 临时开挂，前文没铺垫 |
| **围观** | 让胜利被看见 | 旁观者改口、对手失态、消息传开 | 省略围观，爽感减半 |

**四拍的比例**：嘲讽 2、压制 3、反转 2、围观 2。反转不要最长，围观不要最短。

## 三、爽点类型与风险

| 类型 | 爽在哪 | 风险 |
|---|---|---|
| **身份反转** | 被轻视的人其实是大佬 | 身份揭晓后没有新矛盾，立刻泄气 |
| **越级挑战** | 以弱胜强的肾上腺素 | 越级幅度太大，合理性崩 |
| **智斗** | 读者跟着算、最后发现自己被算 | 反派必须真的聪明，不能靠作者降智 |
| **资源到手** | 确定性奖励、数值成长 | 只报数字，没有使用场景 |
| **护短** | 主角为自己人出头 | 被护的人要有存在感，不能是道具 |
| **复仇** | 长期压抑的总爆发 | 拖太久，读者已经不在乎 |
| **被看见** | 长期被忽视的人终于被承认 | 承认要来自具体的人，不是旁白 |

## 四、爽点升级链

同一个爽点不能重复三次。升级的三个维度：

1. **对手级别**：小混混 → 家族子弟 → 宗门长老 → 一城之主。
2. **代价**：赢了没事 → 赢了断一条路 → 赢了失去一个人。
3. **见证者**：一个人看见 → 一群人看见 → 整个势力看见。

每卷至少升级一个维度；三个都不升级，读者会觉得「又是这一套」。

## 五、节奏：免费与付费不同

> 兑现的**间隔**由这一节定；一章内部的起承转合（起—压—爆—收）见 `rhythm.md`。

- **免费**：一小兑现 / 1 章，大兑现 / 3–5 章。断档两章，追读就掉。
- **付费**：小兑现 / 2 章，大兑现 / 5–8 章。允许蓄力，但蓄力章要有新信息，不能纯憋。
- **卷末**：必须有卷级大兑现，且兑现方式要和卷初的承诺对上。

### 断档检测

- 连续 2 章没有「读者可指认的进展」= 断档。
- 连续 3 章同一个对手、同一个场景 = 疲劳。
- 连续 2 章只有对话没有行动 = 读者会觉得「在水」。

## 六、情绪债

爽点的本质是**读者替主角记的账**。

- 谁欠主角一个道歉？谁欠他一条命？谁抢了他的东西？
- 这笔债要在前文**具体地**记下（当众羞辱、夺走资源、伤害他护的人）。
- 还债时必须**当众**、**加倍**、**由欠债人自己承受**。
- 债还完，要立刻开新债；否则故事失去动力。

## 七、爽点与人物

- 爽点必须**符合主角的性格**：隐忍型的主角爆发要更狠、更晚；张扬型的主角可以当场打回去。
- 反派要有**自己的逻辑**：他为什么看不起主角？他的利益是什么？他输在哪一步判断？
- 配角不是观众：至少有一个配角会因为主角的胜利**改变立场**。

## 八、自检

- [ ] 这一段的「压抑」够不够？读者有没有替主角难受过？
- [ ] 反转用的信息，前文有没有埋过？埋在哪一章？
- [ ] 有没有围观者？他们的反应具体吗？
- [ ] 赢了之后，主角付出了什么？没有代价的胜利不值钱。
- [ ] 这个爽点和上一个是不是同一种？升级了哪个维度？
- [ ] 反派输得合理吗？他有没有犯「只有主角能犯的错」？
- [ ] 还完这笔债，下一笔债是什么？
