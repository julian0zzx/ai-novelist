# 书名、角色名、标签与简介（Naming）

> 书名是**最短的广告**，角色名是**最长的记忆点**，简介是**投稿时唯一会被读完的正文**。
> 三者共同的敌人是：空、泛、AI 味。

## 一、书名的三要素

一个可用的网文书名，通常同时给出两到三样：

| 要素 | 作用 | 例子结构（非真实书名） |
|---|---|---|
| **题材词** | 让读者一秒知道看什么 | 修仙、末世、科举、宅斗、悬疑 |
| **身份/能力** | 给出主角的独特性 | 我在××当××、我的××能×× |
| **冲突/爽点** | 给出「接下来会发生什么」 | 从××开始、开局××、却被×× |

### 常用结构

- **身份 + 反差**：《我在[高端场所]当[底层职业]》
- **能力 + 代价**：《我的[能力]有[副作用]》
- **时间 + 行动**：《重生后我[具体行动]》
- **关系 + 冲突**：《[身份]他[不肯/偏要]××》
- **悬念 + 场景**：《[地点]的[异常事物]》

结构是脚手架，不是答案。填进去的词必须**具体、有画面、能判断题材**。

### 反例

| 类型 | 为什么不行 |
|---|---|
| 抽象文艺（《浮世》《长夜》《山河故人》） | 读者不知道题材，也不知道爽点 |
| 只有情绪（《我很难过》《重生之痛》） | 没有事件，没有承诺 |
| 烂大街（《重生之路》《最强系统》《绝世神医》） | 信息量为零，搜索里沉底 |
| 太长太绕（超过 15 字、含生僻字） | 记不住、打不出来、传播不了 |
| 标题党与内容不符 | 点进来就掉，完读率反噬 |

### 3 秒测试

1. 只看书名，能不能说出**题材**？
2. 能不能说出**主角要干什么**？
3. 会不会想点进去看第一章？

三个都答不出，重起。

## 二、角色名

### 主角

- **好读**：两个字为主，声调有起伏，不用生僻字。
- **有记忆点**：一个具体的字/意象，而不是「叶辰」「苏念」这类高频组合。
- **不撞书名**：主角名不要和书名里的关键词重复。
- **能喊出口**：想象配角在危急时喊这个名字，顺不顺。

### 反派

- **文雅、冷静、有分量**：反派的强大先从名字的气质来。
- 不要用和主角同偏旁、同音的字，读者会混。
- 大反派的名字可以比主角更长、更正式；小反派可以更市井。

### 配角

- 一人一个**语言指纹**：句长、口头禅、称呼方式、发火时的反应。
- 名字可以更普通，但**不要同姓扎堆**；同姓要有明确区分（老大/老二、职务）。

### 命名避坑

- 同一本书里不要出现两个读音相近的名字。
- 不要用需要注释才能读对的字。
- 不要给所有女性角色起「柔/婉/雪/月」，所有男性角色起「辰/昊/轩/宇」。
- 名字要有**时代感**：古代、民国、现代、末世，取名逻辑不同。

## 三、标签

标签是给平台算法和读者看的**分类信号**，不是作文。

- 3–5 个，覆盖：**题材 + 频道 + 核心爽点 + 风格**。
- 用平台现有的标签词，不要自创。
- 不要堆互相矛盾的标签（「甜宠」+「虐恋」+「无CP」）。
- 标签要和前三章的实际内容一致；挂羊头卖狗肉会反噬完读。

## 四、简介

简介不是故事梗概，是**第一章之前的最后一个钩子**。准备三版：

### 1. 一句话版（30 字内）

```
[身份] + [困境] + [他决定做一件什么事]
```

### 2. 一段版（100–150 字）

- 第一句：异常/冲突（不要从「在一个……」开始）。
- 第二句：主角的目标与阻力。
- 第三句：代价或反转。
- 最后一句：钩子（不要总结主题）。

### 3. 三章版（投稿用，300–500 字）

- 第一章的事件。
- 第二章的升级。
- 第三章的承诺/反转。
- 结尾留一个具体问题，不要「他将何去何从」。

### 简介自检

- [ ] 第一句有没有事件？
- [ ] 有没有说清主角要什么？
- [ ] 有没有一个具体的对手/阻力？
- [ ] 有没有一句能被记住的话？
- [ ] 有没有剧透结局？（不要）
- [ ] 有没有 AI 味套话（「命运的齿轮开始转动」「一切才刚刚开始」）？

## 五、改名与 A/B

- 书名可以准备 3–5 个候选，记录每个的**关键词、爽点、目标读者**（`novel_plan operation="naming"`）。
- 上线后看点击率与首章读完率：点击低改书名/封面，读完低改开篇，不要混为一谈。
- 改名不要频繁；每次改名至少观察一个完整推荐周期。
