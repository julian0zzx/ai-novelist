# 连贯性（Continuity）

> 读者弃书只有两个原因：**不好看**，和**对不上**。连载里最贵的错误，是第 80 章和第 12 章打架。
> 本表按账本查，不靠通读记忆；能记进 `novel_bible` 的，不要只留在脑子里。

## 一、五个账本

连贯性不是一种能力，是五种记录。每一种崩掉的样子不同，查法也不同：

| 账本 | 记什么 | 崩了的样子 | 记在哪 |
|---|---|---|---|
| **时间** | 事件发生在第几日、什么时辰、什么季节 | 倒计时不走；三日后的伤第二天就好 | 章节契约的 `timeAnchor` |
| **人物** | 谁在场、谁死了、谁伤了、称谓与辈分 | 已死的人又出场；断过的腿又好了 | `novel_bible` character（含 `exit`） |
| **信息** | 谁知道什么、什么时候知道的 | 角色说出了他不可能知道的事 | 本章契约的 `infoGap` |
| **物品与能力** | 道具来源去向、等级数值、金手指代价 | 一次性的东西复活；代价突然不收 | `novel_plan operation="cheat"` |
| **世界规则** | 规则、距离、势力、货币 | 规则为剧情临时改写；说不通的赶路 | `novel_bible` world |

再加一本**承诺账本**：伏笔与钩子写进 `novel_bible kind="link"`（planted / due / payoff），
到期未收的会被报成逾期——那是同一类欠账，只是查法已经自动化了。

## 二、时间账本

先分清两个时间：**故事内时间**（人物经历了多久）和**叙事时间**（读者读了多久）。
倒计时、伤病、季节、年龄，全按故事内时间算。

### 写法

- 每章一个**时间锚点**，写进契约：`第三日 黄昏`、`三日后`、`十年前`。不写锚点的章节，
  过二十章就没人知道它发生在什么时候。
- 锚点要能连成线：这一章的「次日」和上一章的「三日后」必须对得上。
- 大跨度用**事件标记**，不用模糊词：写「灵潮退去后的第二年」，不写「很久以后」。

### 五个常见错

1. **倒计时不走**：「还有三天」立了三章，读者一算过了七天。
2. **三日变次日**：埋伤时说「三个月不能动」，下一章已经开打。
3. **季节倒错**：上一章下雪，下一章蝉鸣，故事内只过了两天。
4. **回忆无标记**：闪回不标时间，读者把回忆当现在。
5. **同一天两次入夜**：同一章里「天亮了」出现两次；或赶路三天，抵达时还是当天下午。

检查法：把各章 `timeAnchor` 按章序拉成一条线（`novel_status detail="bible"` 会按章打印），
逐条看有没有逆向、缺口、和「三日后」自相矛盾。

**工具已经在查一部分**：`novel_bible kind="review"` 会读每章锚点，按章序算出一个故事日，
把「第 N 章早于前一章已到的第 M 日」报成逆序，并列出缺锚点、锚点无法解析的章。
它只认能算的写法（`第 N 日`、`N 日后`、`次日`、`同日`、`回忆` 算倒叙跳过），
认不出的（`灵潮退去后的第二年`）只报「无法解析」，不会瞎猜成逆序——所以写法统一，检查才有用。

## 三、人物账本

### 死亡与退场

死人不能自己走回来。每个退场人物在 `novel_bible` 里写 `exit`（第几章、怎么退的），
复活必须是**明写的剧情**并付代价，不能是作者忘了。

### 称谓与辈分

- 同一关系只有一种叫法：师叔不能一章叫「师叔」一章叫「长老」。
- 辈分与年龄要能对上；称呼随关系变化要写清是哪一章变的。
- 化名要登记：谁知道真名、什么时候知道的。

### 身体与伤

断过的腿、瞎过的眼、烧掉的疤，是全书的资产，不是一次性的描写。伤要按故事内时间愈合，
愈合不了的要一直带着——那反而是人物记忆点。

### 性格底线

人物可以变，但不能无缘无故变。上一章怕水，这一章下水，要么给出理由，要么就是在换人。
成长弧光写在 `novel_bible` 的 `growthArc` 里，改人设先改那一行。

## 四、信息账本（最容易崩的一本）

三方信息必须分开记：**读者知道** / **角色知道** / **作者知道**。

- 角色不能说出他不知道的事——这是最刺眼的一种崩。
- 读者知道、角色不知道，是悬念；角色知道、读者不知道，是反转；两者都用错，就成了逻辑漏洞。
- 每个秘密至少标三样：**谁知道**、**第几章知道的**、**怎么知道的**。写「揭晓章」之前，
  往前找三条「他早就该知道」的证据，找不齐就先补。
- 误会类剧情要写明「为什么没解开」。有理由的误会叫张力，没理由的叫降智。

## 五、物品与能力账本

- **金手指的代价要一直收利息**：代价只在第一章收过一次，后面就等于没有代价（见 `cheat` 的 cost）。
- 道具登记来源、去向、消耗：给出去的东西不能再从口袋里掏出来。
- 等级、数值、排名不能倒挂：写过「他是宗门第一」，就不能被随便一个外门弟子压着打，
  除非剧情明写他为何不出手。
- 一次性的大招不能连放两次；能连放两次的，第一次就不该叫「只能一次」。

## 六、世界规则账本

- **规则先立后用**：读者接受规则在前，剧情用规则在后。反过来就是「主角需要什么就有什么」。
- **例外要付代价**：破一次规则，就要付出一次读者看得见的代价，否则规则作废。
- 地图要能量距离：从 A 到 B 几天，写一次就固定下来。
- 势力关系要有变化记录：谁和谁结盟、谁叛了，不能只在需要时想起来。

## 七、改稿时的检查顺序

按「崩了最贵」排序，不要一上来就润色：

1. **信息**：这一章有没有人说了他不该知道的话？
2. **时间**：锚点对得上上一章吗？倒计时走了吗？
3. **人物**：死者、伤者、称谓、性格有没有越界？
4. **物品与规则**：用掉的东西有没有回来？规则有没有为剧情让路？
5. **文风**：以上都对，再按 `voice.md` 改句子。

## 八、自检

- [ ] 本章的 `timeAnchor` 写了吗？和上一章连得上吗？写法是 `第 N 日` / `N 日后` 这类可算的形式吗？
- [ ] `novel_bible kind="review"` 的时间线一行看过吗？逆序要么改锚点，要么标「回忆」。
- [ ] 本章出场的人，有没有已经退场或不该在场的？
- [ ] 这一章有谁知道了一个新秘密？记进账本了吗？
- [ ] 有没有人说出他不可能知道的事？
- [ ] 用过的一次性道具、能力、底牌，有没有偷偷回来？
- [ ] 金手指的代价，这一卷收过利息吗？
- [ ] 有没有为了让剧情通过，临时改了世界规则？
- [ ] `novel_bible` 里该记的（exit / link / relations），是不是还只在脑子里？
