# 同人创作（Fan Fiction）

> 同人是在**别人的世界里写自己的故事**。它最自由，也最容易踩线：踩线不是文笔问题，是账号和作品会消失。
> 本表给二创边界与合规判断，不替代法律意见；平台规则与授权状态以当期公告和权利方声明为准。

## 一、先分清四种同人

| 类型 | 说明 | 风险 |
|---|---|---|
| **原作向** | 沿用原作人物、设定、时间线，写未发生的剧情 | 中：情节越靠近原作越安全，越改写核心越危险 |
| **AU / 架空** | 人物保留，世界换成校园/末世/古代 | 中：人物形象仍是原作的，不能算原创 |
| **Crossover** | 两个及以上作品混写 | 高：同时涉及多个权利方 |
| **原创向** | 只借用世界观类型，人物与情节全新 | 低：接近原创，但仍要避免特有名词与设定 |

**判断口径**：借的是「类型」还是「具体表达」。类型（修真、无限流）不受保护；人物、专有名词、独特设定、
具体情节受保护。抄设定名、抄名场面、抄人物关系网，都是最容易被认定侵权的三件事。

## 二、合规清单（发布前逐条过）

- [ ] **是否商用**：付费、打赏、广告、出版、影视授权都属于商用，风险等级完全不同。
- [ ] **是否声明**：注明原作、作者、二创性质；不声明等于默认主张原创。
- [ ] **是否搬运**：有没有直接复制原作段落、台词、章节。引用一两句和整段搬运是两回事。
- [ ] **是否影射真人**：RPS（真人同人）涉及名誉权与隐私，风险最高，很多平台直接禁止。
- [ ] **是否触碰平台红线**：各平台对同人的容忍度差别很大，发布前查当期规则，不要按「别人也这么写」判断。
- [ ] **是否涉及未成年人与性内容**：这是全球平台最一致的红线，没有例外。
- [ ] **是否签了独家**：签约作品通常禁止同人或二创，先看合同。

## 三、发布规范

- **标注四件套**：原作 / CP（如有）/ 分级 / 内容预警（character death、暴力、自伤等）。
- **分级要保守**：不确定就往上标一级；被举报的代价远大于少一批读者。
- **不打原作 tag 蹭流量**：用「同人」「二创」等区分标签，把原作 tag 留给原作讨论。
- **不接商业推广**：同人号接广告，等于把二创直接变成商用。

## 四、写作层面的三个难点

1. **OOC（人物崩坏）**：同人读者对人物的容忍度最低。写之前列三条这个人「绝不会做的事」，
   每次让他做反常的事都要给理由。
2. **原作包袱**：读者已经知道原作的结局。你的张力不能来自「会发生什么」，只能来自「这次会怎么不同」。
3. **原创性焦虑**：想让同人「像自己的作品」，就得换掉借来的东西——见下一节。

## 五、同人转原创：四换一改

想把同人改成能签约的原创，逐项替换，不要只改名字：

| 换什么 | 换成什么 | 只改名字的后果 |
|---|---|---|
| **人物** | 换身份、换欲望、换缺陷，保留「关系功能」 | 读者一眼认出，编辑也认得出 |
| **世界** | 换力量体系、换势力结构、换地理 | 设定名词一换，人物行为逻辑就断了 |
| **关系网** | 换谁欠谁、谁背叛谁 | 关系不变，故事就是原作的影子 |
| **关键情节** | 换冲突的起因和代价 | 名场面照搬是最硬的侵权证据 |
| **一改** | 改叙事视角或时间结构 | 换视角能让旧材料长出新东西 |

四换做完，再检查一遍：把人物名全遮住，还有没有一段能让原作读者说「这就是那本书」？有，就继续换。

## 六、把同人当练习，而不是当作品

同人最适合练三件事：**人物声音**（已有的人物，你写不写得像）、**关系张力**（不用建世界就能写冲突）、
**短篇完成度**（一次写完一个故事）。练完把结论写进 `novel_repo operation="lesson"`，
下一本原创直接用。

## 七、自检

- [ ] 借的是类型，还是具体的人物/设定/情节？
- [ ] 商用与否？平台规则查过当期版本吗？
- [ ] 标注四件套齐了吗？分级是否保守？
- [ ] 有没有整段搬运原作文字？
- [ ] 主要人物有没有三条「绝不会做」的底线？违反时给了理由吗？
- [ ] 若要转原创，四换一改做到哪一步了？遮住名字还认得出吗？
