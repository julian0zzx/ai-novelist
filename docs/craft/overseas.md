# 英文出海（Overseas & English Web Fiction）

> 出海不是把中文稿翻译一遍，是**用英文读者的期待重写一遍节奏**。同一个故事，中文能靠信息密度撑住，
> 英文要靠场景和因果撑住。本表给判断方法；平台规则、字数区间都以当期官方指南为准。

## 一、先判断：你是「翻译出海」还是「原生英文」

| | 翻译出海 | 原生英文 |
|---|---|---|
| 读者 | 华人读者、华语圈 | 英语母语读者（Royal Road / Wattpad / Amazon） |
| 主要风险 | 翻译腔、成语直译、称谓混乱 | 文化背景缺失、爽点不成立、节奏太慢 |
| 该改什么 | 句法、比喻、称谓、度量衡 | 动机、因果、场景密度、人物主动性 |

**最危险的是中间态**：用中文的叙事逻辑写英文句子。读者说不出哪里怪，但会弃书。
判断方法：把第一章给一个英语母语读者读，问「这个人为什么现在要这么做」——答不出来就是中间态。

## 二、英文读者要什么

- **动机先行**：主角为什么现在必须行动，第一章就要给。中文可以「先写处境，再写动机」，英文更吃「先给目标」。
- **因果外显**：中文读者能脑补的省略，英文读者会当成漏洞。该写的连接（因为、所以、代价）要写出来。
- **能力可量化**：progression fantasy / LitRPG 的读者要看数值、等级、技能树；模糊的「变强了」不成立。
- **场景密度高**：一章至少一个完整场景（目标—阻力—结果），不要整章内心独白。
- **第一人称常见**：Royal Road 上大量第一人称、现在时；中文习惯的第三人称限知不是默认值。

## 三、语言层面的八个坑

1. **成语直译**：卧薪尝胆 / 破釜沉舟 / 三十年河东，直译等于零信息。换成具体动作或直接删。
2. **称谓系统**：师兄/师姐/师尊/长老没有对应词。要么用拼音加注释（sect / shifu），要么改成
   mentor / senior / elder，**全书统一一种**。
3. **度量衡与货币**：里、斤、两、灵石，换成读者能感知的比较（「走三天」「一个月的工钱」）。
4. **名字**：两三个音节、拼写可读、不要全员 X 开头。中文名保留时，第一次出现给一次发音提示。
5. **翻译腔**：`It is worth noting that` / `In this process` / `not A but B` 的中文版对应物，
   在英文里更刺眼。删连接词，让句子并置。
6. **比喻体系**：龙、凤凰、麒麟对英文读者是异域装饰；要保留就给出功能（它能做什么），不要只给意象。
7. **时态**：现在时写动作、过去时写回忆，全书统一；不要为了「文学感」来回切。
8. **章节长度**：英文网文单章通常比中文长（经验值 2000–4000 词），但每章仍要一个完整节拍。

## 四、平台差异（经验值，不是规则）

| 平台 | 读者要什么 | 开篇 | 单章 | 常见死法 |
|---|---|---|---|---|
| **Royal Road** | progression、系统、长线成长 | 第一章给能力与代价 | 2000–4000 词 | 前五章还在铺垫；数值不透明 |
| **Wattpad** | 青春、关系、强情绪 | 第一段就是关系冲突 | 1000–1500 词 | 章节太短没有推进；更新断档 |
| **Webnovel（起点国际）** | 系统/修真/升级，中文节奏 | 第一章给金手指 | 1500–2500 词 | 中文式铺垫；翻译腔 |
| **Amazon / KU** | 完本、系列、可一口气读 | 样章前 10% 必须留人 | 全书 6–10 万字 | 单本太短、结尾不闭合 |

## 五、出海要额外准备的材料

- **术语表（glossary）**：人名、地名、功法、境界、货币，一栏中文一栏英文，全书只此一份。
- **章节标题**：英文标题要能独立成立（`Chapter 12: The Debt`），不要直译中文四字标题。
- **简介（blurb）**：三句式——谁、要什么、什么挡着；不要写世界观。
- **标签（tags）**：平台靠标签分发，选 5–10 个现有标签，不要自创。
- **分级与预警**：暴力、性、自伤等内容，按平台要求标注。

## 六、改编不是翻译：三个必须重写的地方

1. **第一章**：中文版的第一段是处境，英文版的第一段要是**已经发生的动作**。
2. **爽点**：中文的「打脸」靠围观者反应，英文更认「能力被量化证明」。两种都要给，但顺序不同。
3. **关系**：中文的辈分与礼数，英文读者读不出重量。把「礼数」换成「谁欠谁、谁有权力」的具体事件。

## 七、自检

- [ ] 第一章能不能用一句英文说出主角「为什么现在必须行动」？
- [ ] 术语表建了吗？全书称谓、度量衡、境界名是否统一？
- [ ] 有没有直译的成语、谚语、四字词？
- [ ] 每章有没有一个完整场景（目标—阻力—结果）？
- [ ] 数值/等级/技能是否可量化、可比较？
- [ ] 单章词数、更新频率是否匹配目标平台的当期习惯？
- [ ] 有没有找过英语母语读者读前三章，并记录他们卡住的地方？
