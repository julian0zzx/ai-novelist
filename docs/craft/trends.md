# 趋势与选题调研（Trends）

> 趋势调研的目的不是「现在什么火」，是**找到读者还在等、但书架上没被满足的那一格**。
> 榜单是结果，不是原因；照着榜单写，最多写到第二名。本表给采样与判断方法，不预测任何题材的冷热。

## 一、先定问题

调研之前先写下你要回答的那一个问题。常见三种：

- **选题**：这个赛道现在供给够不够？我要不要进？
- **定位**：同类书都在写什么，我能差在哪一格？
- **开篇**：读者现在对第一章的耐心是几段？

问题不同，样本不同。没有问题的调研，最后只会得到一句「现在都写系统」。

## 二、样本：去哪看，看多少

| 来源 | 看什么 | 用途 |
|---|---|---|
| **畅销榜/热销榜** | 前 20–30 名 | 现在被验证的题材与写法 |
| **新书榜/潜力榜** | 近 30 天上榜的新书 | 平台正在推什么（比畅销榜更早） |
| **完本榜** | 完结且数据好的 | 哪些题材能长期写、能收尾 |
| **分类页** | 分类下的作品数量与更新量 | 供给密度：太挤还是太荒 |
| **评论区/书评区** | 高频出现的抱怨 | 供给缺口藏在这里 |

> 平台会变：榜单口径、推荐位、分类都在改。**每次调研记下采样日期和平台**，结论超过一个月就要复核。

## 三、记录表（照这个填，不要凭印象）

| 字段 | 记什么 |
|---|---|
| 书名 / 作者 | —— |
| 题材 / 频道 | 主赛道 + 调味 |
| 开篇钩 | 第一章前 300 字在做什么 |
| 章级兑现 | 每 2–3 章给读者什么 |
| 单章字数 / 更新 | 经验值区间 |
| 上榜位置 / 时间 | 判断是自然上榜还是推荐位 |
| 读者抱怨 | 书评区最高频的三条 |

样本量：一个赛道至少 10 本，理想 20–30 本。少于 10 本，你看到的是个人口味。

## 四、四个必须防的偏差

1. **幸存者偏差**：你只看到活下来的书，看不到同样写法扑掉的九十九本。
2. **推荐位偏差**：榜上很多书是被推上去的，不是自然长起来的。看它有没有断更、追读是否稳定。
3. **时间点偏差**：某些书赶上了平台拉新或题材红利，换个时间写不一定成立。
4. **作者积累偏差**：老作者的新书自带读者，新人照抄结构也起不来。

## 五、从数据到假设

调研的产出**不是结论，是假设**，交给流程去验证：

1. 写一句假设：「如果我把 A 赛道的 B 元素加到 C 题材里，读者会为 ___ 追读」。
2. 用 `novel_plan operation="competitor"` 把 3–5 本对标书拆开（开篇事件、金手指、爽点频率、情绪曲线、付费点）。
3. 用 `novel_review operation="competitor"` 拆正文，拿到可复用的结构与要避开的写法。
4. 写成 `novel_plan operation="pitch"` 的一句话卖点和差异化，再用开篇包验证。

**不要在调研阶段下「这个题材能火」的结论**——那是数据评估（`novel_assess`）才有资格说的话，
而且要在你自己的书上了榜之后。

## 六、找供给缺口的三条线索

- **抱怨**：书评区反复出现的「后期崩了」「女主降智」「金手指太强」，就是读者在告诉你缺什么。
- **空分类**：分类里作品少、但同类在别的平台火——可能是迁移机会，也可能是这个平台的读者不吃。
- **老题材新写法**：题材老不等于没机会，换个视角、换个代价、换个节奏，老题材能再写一轮。

## 七、自检

- [ ] 调研前写下了要回答的那一个问题吗？
- [ ] 样本够 10 本吗？是否覆盖畅销、新书、完本三类？
- [ ] 记录表填了吗，还是只有印象？
- [ ] 有没有把推荐位当成自然数据？
- [ ] 结论写成了可验证的假设，而不是「现在流行 X」？
- [ ] 采样日期记了吗？超过一个月有没有复核？
