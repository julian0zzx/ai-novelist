# 剧本与改编（Script & Adaptation）

> 小说写给读者的想象，剧本写给观众的耳朵和眼睛。**能用画面和台词说出来的，才留在剧本里**；
> 其余全部要改写成行动。本表给格式与改写方法，具体稿酬、集数、时长以甲方与平台要求为准。

## 一、小说与剧本的五处不同

| | 小说 | 剧本 |
|---|---|---|
| 载体 | 读者的想象 | 画面 + 声音 |
| 心理描写 | 可以直接写「他想」 | 只能外化为动作、台词、道具、沉默 |
| 视角 | 叙述者可以解释 | 镜头只能拍「看得见、听得见」的 |
| 篇幅 | 按字数 | 按页/场/集，一页约一分钟（经验值） |
| 节奏 | 可以慢 | 前三秒/第一场必须给冲突 |

**改写的第一动作**：把每一段心理描写翻译成一个可拍的动作。翻译不出来，就说明这段在剧本里不该存在。

## 二、格式：一场戏的五个部分

```
第 3 场  内景  当铺  夜

　　柜台上摆着一只断了把手的茶杯。陈默把当票推回去。
　　掌柜没接，反而把茶杯往里挪了半寸。

　　陈　　　　这杯子不值这个价。
　　掌柜　　　（不看杯子）值不值，看你急不急。

　　（陈默的手指在当票边缘停住。）
```

1. **场景头**：场号 + 内/外景 + 地点 + 时间（日/夜/黄昏）。四样缺一样，制片就没法排期。
2. **动作行**：只写镜头能拍到的。现在时、短句、一段不超过三行。
3. **人物名**：单独一行，顶格，后接台词。
4. **台词**：口语、短、有潜台词；括号里的表演提示能不用就不用。
5. **转场**：只在必要处标（切/淡出），不要每场都写。

## 三、把一章小说改成一场戏

1. **找目标**：这场戏里，谁想要什么？（只能是具体、当下、可失败的东西）
2. **找阻力**：谁或什么挡着？阻力必须在这场戏里出现，不能靠旁白交代。
3. **删解释**：所有「因为」「所以」「这意味着」，能变成动作就变，变不了就删。
4. **压台词**：一句台词只承担一个功能（推进、暴露、拒绝）。信息太多就拆成两场。
5. **留一个钩**：这场戏结束时，观众要知道下一场要发生什么。

## 四、短剧与长剧的节奏差

- **竖屏短剧**：单集 1–2 分钟，前 3 秒给冲突，每集一个反转，集尾必须断在悬念上；
  全集 60–100 集，主线一句话说清。
- **横屏网剧/长剧**：单集 40 分钟，一场戏可以慢，但每集要有一次推进和一次代价。
- **电影**：三幕，第一幕 25% 内建立欲望与阻力，第二幕中点翻转，第三幕收束。

> 时长与集数是经验值，不是规则。谈项目时以甲方给的单集时长与总集数为准，再倒推节奏。

## 五、改编顺序（别从第一页开始改）

1. **先写一句话主线**：谁，要什么，什么挡着，最后付出什么。
2. **再列场次表**：每场一行——目标、阻力、结果。没有结果的一场就是废场。
3. **再定结构**：把场次表按三幕/集数分配，先确认高潮与结尾。
4. **最后写对白**：到了这一步，台词只是把已经成立的冲突说出来。

## 六、常见死法

- **旁白太多**：用旁白交代设定，观众会换台。设定只能通过人物的选择和代价露出来。
- **台词念设定**：「你知道的，我们门派三百年前……」——没人这样说话。
- **场景没有目标**：人物在场景里聊天、回忆、感慨，但没人想要什么。
- **把小说逐句搬**：小说的节奏是阅读节奏，剧本的节奏是生理节奏（眨眼、呼吸、走位）。
- **人物太多**：剧本里每多一个有名字的人，制作成本就涨一次。能合并就合并。

## 七、自检

- [ ] 每一场都能用「谁想要什么、谁挡着、结果如何」说清吗？
- [ ] 有没有一段是「只有读者能知道、观众看不到」的信息？改掉或删掉。
- [ ] 场景头四要素是否齐全？
- [ ] 台词是否一人一句只干一件事？
- [ ] 第一场/前 3 秒有没有冲突？
- [ ] 有没有为了省成本而可以合并的人物或场景？
- [ ] 主线能不能一句话说清？
