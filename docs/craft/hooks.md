# 钩子（Hooks）

> 钩子不是「悬念」的同义词。钩子是**读者为了知道下一步而愿意继续读的那个未完成动作**。
> 判断标准只有一条：删掉这句话，读者还会不会想知道「然后呢」。

## 一、钩子的三种燃料

| 燃料 | 读者在等什么 | 例子 |
|---|---|---|
| **威胁** | 坏事什么时候落下、主角怎么挡 | 门外的人已经开始砸锁 |
| **信息差** | 主角不知道、读者知道一半 | 她笑着收下钱，没看见信封背面的名字 |
| **承诺** | 主角说了要做，但还没做到 | 「三天后，我来取你的命」 |

三种燃料可以叠加，但**一章只点一次火**。每段都埋钩，等于没有钩。

## 二、开篇 300 字

开篇不是「介绍」，是**已经开始的现场**。前 300 字至少让读者拿到三样：

1. **谁**：一个可指认的人，不是「少年」「男子」。
2. **要什么**：一个具体的、当下就要解决的目标。
3. **阻力**：一个具体的人或规则挡着他。

### 三种可用开场

- **危机中**：主角已经在挨打、在被赶、在倒计时里。
- **反差中**：身份与处境错位（大佬装废物、废物握着重宝）。
- **异常日常**：一切正常，只有一处不对劲（镜子里的影子慢半拍）。

### 三种高风险开场

- **天气/风景开场**：除非风景本身在杀人，否则读者不关心。
- **回忆开场**：读者还没认识这个人，不关心他的过去。
- **设定说明开场**：世界再大，也得先有一个人在里面疼。

### 开篇自检

- [ ] 第一段有没有一个**动作**（不是状态、不是判断）？
- [ ] 读者能不能用一句话说出「主角现在要干什么」？
- [ ] 第一章结束前，有没有一个**必须翻下一章**的理由？
- [ ] 有没有在第一章塞进超过 3 个专有名词？删到 3 个以内。
- [ ] 主角有没有做**一个选择**？只被推着走的主角不抓人。

## 三、章末钩的六种断法

| 断法 | 断在哪 | 注意 |
|---|---|---|
| **决定** | 主角说「我去」/「我不走」的瞬间 | 决定要有代价，不能空喊 |
| **发现** | 拉开抽屉/看到名字/听见半句话 | 信息要具体，不要「他发现了秘密」 |
| **倒计时** | 「还有三天」 | 倒计时必须真的走，不能下章就忘 |
| **误解** | 一方看见不该看的画面 | 误会要能靠后文解开，不能靠降智维持 |
| **代价** | 赢了，但失去了什么 | 代价要当场可见 |
| **身份揭示** | 只揭一半 | 揭完就失去张力；留一个「为什么」 |

### 断章的位置

- **断在动作前**：他抬手，门开了——切章。不要断在动作完成后。
- **断在信息落点**：医生说「你母亲的名字，不在这份名单上」——切章。
- **不要断在情绪总结**：「他心中五味杂陈」不是钩子，是句号。
- **不要断在空话**：「欲知后事如何」「一切才刚刚开始」——读者已经不信了。

## 四、付费点 / 上架卡点

付费点的钩子和普通章末钩不同：读者要在这里**决定要不要付钱**。

- 断在**最大的信息差**上，不要断在打斗中间。
- 前一小段先给一次**小兑现**（让读者觉得钱花得值），再把大钩子抛出来。
- 钩子要指向**具体的下一步**：不是「更大的阴谋」，而是「明天，他要去见那个人」。
- 上架前的 3 章不要连续断在同一个角色身上；换视角、换场景，避免疲劳。

## 五、钩子的兑现纪律

- 埋下的钩子必须登记：埋点章、预计回收章、回收方式（`novel_bible kind="link"`）。
- **每 3 章至少兑现一个旧钩**，否则读者会认为作者忘了。
- 回收时给的信息要**比读者猜的多一点**；完全猜中等于没写，完全猜不中等于没铺垫。
- 一个钩子最多拖一卷；跨卷不回收，就要在卷末给一个阶段性答案。

## 六、钩子与节奏的配合

- 连续 3 章高强度钩子 → 读者疲劳，需要一章「小胜 + 生活感」缓冲。
- 缓冲章也要有钩，只是钩子更轻（关系推进、资源到手、新地图开门）。
- 每卷末必须有一个**卷级大钩**：不是下一章的事，是下一卷的事。

## 七、写完一章的 8 问

1. 这章结尾，读者最想知道的是什么？能不能用一句话说出来？
2. 这个钩子是威胁、信息差，还是承诺？
3. 下一章开头能不能直接接上？还是会先写一段无关日常？
4. 这章有没有兑现上一章留下的钩子？没有的话，凭什么让读者再等一章？
5. 章末断在动作前，还是断在总结后？
6. 钩子是否具体到人/地点/时间？「更大的危险」不算。
7. 这一章有没有至少一个「读者会截图发群」的瞬间？
8. 如果读者在这里弃书，最可能因为哪一句？
